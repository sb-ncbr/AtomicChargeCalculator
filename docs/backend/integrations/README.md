# Integrations
Integrations serve as a *low level* layer providing access to the charge engine ([ChargeFW](https://github.com/sb-ncbr/chargefw), behind the [`ChargeEngine` interface](../../../src/backend/app/integrations/chargefw/base.py)) and the filesystem. They are then used in [services](../../../src/backend/app/services/). The goal is to decouple these implementations from services, making a future replacement easier.
